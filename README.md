## 3. Config (date, venue, copy)

**Single source of truth:** `src/lib/config.ts`

Edit there for:

- `coupleNames`, `tagline`
- `weddingDate` (YYYY-MM-DD), `weddingTime` (e.g. `"3:00 PM"`)
- `venueName`, `venueAddress`, `venueMapsUrl`
- `capacity` (25), `rsvpDeadline`
- `heroImage`, `storyImage1`, `storyImage2`, `galleryImages` (paths under `/couple-photos/...`)
- `venueEmbedUrl`, `venueVideoUrl`, `photoHashtag` (optional)
- **Dinner:** `dinnerTitle`, `dinnerTime`, `dinnerVenueName`, `dinnerVenueAddress`
- **Travel:** `travelBlurb`, `travelTips` (array of strings; Sacramento/SF tips and drive times)
- **Registry:** `registryUrl`, `registryLabel`
- **Contribute:** `contributeVenmoUrl`, `contributePayPalUrl`, `contributeText`, `contributeZellePdfPath` (e.g. `/zelle-qr.pdf` — put PDF in `static/zelle-qr.pdf`)
- **Shared photos:** `sharedAlbumUrl` (Google Photos / Dropbox link)
- **Planning (Dani & Javad only):** `planningChecklist` (string[]), `rolesAndTasks` (role → list of tasks) — shown at `/planning?token=ADMIN_SECRET`

After changing config: commit, push to `main`; Vercel will redeploy.

## 4. RSVP list: where it lives & how to access

RSVPs are stored in **Supabase** in the table **`rsvps`**.

| Where | How to access |
|-------|----------------|
| **Supabase Table Editor** | [Open `rsvps` table](https://supabase.com/dashboard/project/eabncidlwjdpdrmvpcrc/editor) (Supabase dashboard → Table Editor → `rsvps`). |
| **Your site (admin page)** | Go to **https://dani-and-javad.vercel.app/admin?token=YOUR_ADMIN_SECRET**. You see a table of all RSVPs and a **Download CSV** link. |
| **CSV export URL** | **https://dani-and-javad.vercel.app/api/rsvps/export?token=YOUR_ADMIN_SECRET** — direct download of CSV. |

Columns: `name`, `email`, `attending` (yes/no/waitlist), `plus_one`, `notes`, `created_at`. Capacity is enforced in the app (25 “yes” + plus-ones; overflow goes to waitlist).

## 5. Admin & CSV export

- **Admin secret:** You **choose** it (e.g. a long random string). Set it as `ADMIN_SECRET` in your `.env` and in Vercel → Project → Settings → Environment Variables. Not stored or generated by any service.
- **Admin URL:** `https://dani-and-javad.vercel.app/admin?token=YOUR_ADMIN_SECRET`
- **CSV URL:** `https://dani-and-javad.vercel.app/api/rsvps/export?token=YOUR_ADMIN_SECRET`
- Without the correct `token`, `/admin` redirects to the home page and the export returns 401.

## 6. Calendar (iCal / Google subscribe)

- **Feed URL:** **https://dani-and-javad.vercel.app/api/calendar.ics**
- **One-time add:** On the site, use **Add to Calendar (.ics)** (downloads a file).
- **Subscribe (auto-sync):**
  - **Apple Calendar (iCal):** File → New Calendar Subscription → paste the feed URL above → set refresh (e.g. weekly) → Subscribe.
  - **Google Calendar:** Add other calendars → From URL → paste the same URL → Add calendar.
- The event is built from `config.weddingDate` and `config.weddingTime`. If you change them and redeploy, subscribers get the update on next refresh.

See **`docs/RSVP_AND_CALENDAR.md`** for more detail.

## 7. Environment variables

**Used by the app (see `ENV_VARS.md` for full list):**

| Variable | Required | Where to get / set |
|----------|----------|---------------------|
| `PUBLIC_SUPABASE_URL` | Yes | Supabase → Settings → API → Project URL |
| `SUPABASE_URL` | Yes | Same as above |
| `SUPABASE_ANON_KEY` | Yes | Supabase → API → anon public key |
| `SUPABASE_SERVICE_ROLE_KEY` | For admin/CSV | Supabase → API → service_role key |
| `ADMIN_SECRET` | For /admin & export | You choose; set in .env and Vercel |
| `SITE_URL` | Optional (QR, emails) | e.g. `https://dani-and-javad.vercel.app` |
| `RESEND_API_KEY`, `RESEND_FROM` | Optional (emails) | Resend.com |

- **Local:** `.env` in project root (Wedding Site section). Not committed (`.env` is gitignored).
- **Vercel:** Project → Settings → Environment Variables. If you use Supabase ↔ Vercel integration, set the **public env var prefix** to **`PUBLIC_`** (SvelteKit).

## 11. Optional: photos, map, video, Resend

- **Couple photos:** Add images to **`static/couple-photos/`** (e.g. `hero.jpg`, `story-1.jpg`, `gallery-1.jpg`). In **`src/lib/config.ts`** set `heroImage`, `storyImage1`, `storyImage2`, `galleryImages` (paths like `'/couple-photos/hero.jpg'`). Redeploy.
- **Map embed:** In config set **`venueEmbedUrl`** to the Google Maps iframe `src` (Share → Embed a map).
- **Venue video:** In config set **`venueVideoUrl`** to a YouTube embed URL (e.g. `https://www.youtube.com/embed/VIDEO_ID`).
- **Photo hashtag:** `photoHashtag` (e.g. `'DaniAndJavad'`) is shown in the Gallery. Already set by default.
- **Resend (RSVP emails):** Set `RESEND_API_KEY` and `RESEND_FROM` (and `SITE_URL`) in Vercel; guests get a confirmation email after RSVPing.
