# Notion Wedding Planning Setup

Use this guide to set up your Notion task board and create the initial wedding planning tasks. The Cursor Notion MCP can create these for you once the board is connected.

## 1. Create or connect a task board

- **Option A (new board):** Duplicate the [Code with Notion Board](https://notion.notion.site/code-with-notion-board) template into your workspace (top bar → duplicate).
- **Option B:** Use an existing Notion board that has a Tasks database (Title, Status, Due date, etc.).

Share the board URL with Cursor if you want the agent to create tasks via the Notion MCP (create-task, database-query).

## 2. Initial tasks to create

Add these as tasks (with due dates relative to your wedding date):

| Task | Suggested due |
|------|----------------|
| Apply for park permit (Garrapata / Pfeiffer Big Sur) | 30+ days before wedding (6 months for Pfeiffer) |
| Obtain event liability insurance | Before permit submission |
| Book officiant | 3–6 months before |
| Book photographer | 6–9 months before |
| Book caterer or plan food/drink | 3–4 months before; tie to RSVP headcount |
| Arrange florals/bouquet | 3–4 months before |
| Obtain marriage license (Monterey County Clerk) | 2–4 weeks before (valid 90 days) |
| Send save-the-date | 6–8 months before |
| Send formal invitation / site link | 2–4 months before or 4–6 weeks before RSVP deadline |
| Set RSVP deadline (show on site) | 3–4 weeks before wedding |
| Send reminder to non-responders | Few days before RSVP deadline |
| Confirm witnesses (if public license) | Before wedding |
| Day-of timeline (share with photographer & officiant) | 2 weeks before |
| Send thank-you cards | Within 3 months after |
| Order certified marriage certificate(s) | After officiant files license |

## 3. Optional databases

- **Vendors:** One row per vendor (officiant, photographer, florist, caterer) with contact, contract status, payment due.
- **Budget:** Categories (venue/permit, photography, florals, attire, catering, stationery, contingency ~10–15%).

## 4. Day-of checklist (in Notion or printable)

Vows & vow books, rings in case, attire & accessories, marriage license, witnesses confirmed, bouquet, timeline shared with vendors, restrooms/parking note for guests.
